# Nodeara – CTO & System Architect Sourcing Strategy

## Role Clarity

We are NOT hiring:
- Generic full-stack coder
- Freelancer-only dev
- UI-only engineer

We need hybrid profiles:

1. Growth / Attribution Architect
2. Marketplace System Architect
3. Founding Engineer (part-time → full-time)

---

# Ideal Skillset

Must Understand:
- Marketplace mechanics
- Incentive balancing
- Campaign logic
- Attribution tracking (UTMs, redirects, session validation)
- API-first architecture
- Scalable backend systems
- Anti-fraud basics

Bonus:
- Creator economy platforms
- AdTech / Influencer platforms
- Live commerce infrastructure
- Event-driven architecture

# Interview Test Questions

Whiteboard Exercises:

1. Design tracking system for cross-platform live event routing.
2. How to prevent bot abuse in click-based payout pool?
3. How to structure weighted payout logic?
4. How to design campaign reporting dashboard?
5. How to build modular backend for Phase A → Phase C evolution?

If they cannot discuss attribution mechanics comfortably:
They are not the right architect.
