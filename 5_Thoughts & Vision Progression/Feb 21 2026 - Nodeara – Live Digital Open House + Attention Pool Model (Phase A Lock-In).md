# Phase A Model – Live Digital Open House

## Basic Flow

1. Agent / Developer creates a **Live Digital Open House Campaign**
2. They define:
   - Date
   - Time
   - Budget pool
   - Anchor KOL (optional)
3. Live happens on native platform (IG Live, TikTok Live, Douyin, etc.)
4. All viewers are directed via tracked Nodeara link
5. Nodeara:
   - Tracks click-through
   - Tracks session quality
   - Handles scheduling
   - Aggregates campaign reporting
6. Post-event:
   - Agent receives visual performance dashboard
   - Seller gets professional campaign report

Nodeara does not host video initially.
We route + measure + orchestrate.

# Cross-Creator Amplification Layer

## Campaign Structure

Each Live Digital Open House can include:

### 1. Anchor Host (Mega KOL or Realtor-KOL)
- Fixed guarantee (paid by campaign owner)
- Possible bonus from pool

### 2. Secondary Amplifiers (Mid-tier KOLs)
- Share event before / during live
- Receive performance-based payout from pool

### 3. Open Share Layer (Optional)
- Everyday users can share
- Micro-reward pool
- Capped & weighted payouts

# Tracking & Integrity Model (Early Stage)

We do NOT promise guaranteed sales ROI.

We provide:

- Measurable attention
- Click-through tracking
- Session quality metrics
- Save / schedule attempts
- Time-on-page tracking
- Campaign summary report

Payout logic should NOT be based on raw clicks only.

Weighted system may include:
- Unique session
- Time threshold
- Scroll depth
- Anti-bot filtering
- Cap per user
- Cap per creator

Early stage can be semi-manual before automation.
