## What We’re Building (Clear Version)

We’re building a **push-based discovery feed for listings** where:

- Listings become media objects
    
- Creators amplify them
    
- Engagement becomes structured buyer intent
    
- Attribution is measurable
    

Frontend behavior:  
Social media style feed (TikTok/IG mechanics)

After click:  
Utility layer (maps, scheduling, inquiry, chat, CRM-lite)

Wedge:  
Turn creator distribution into measurable, structured transaction intent.

Not inventing new tech.  
Recombining distribution + intent capture in a high-friction vertical.

## What Makes This Technically Interesting

Hard problems:

- Multi-touch attribution between creators and inquiries
    
- Fraud detection (fake views / fake leads)
    
- Structured intent scoring
    
- Feed ranking logic (not pure engagement-based)
    
- Conversation memory + structured extraction
    
- Transition from media object → transaction object
    

This is not CRUD real estate portal 2.0.  
It’s distribution-to-intent engineering.
