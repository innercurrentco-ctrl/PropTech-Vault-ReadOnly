# Nadara Strategic Architecture Document

## Creator Economy Vertical -- Housing Focus

------------------------------------------------------------------------

# 1. Core Identity

Nadara is a **verticalized Creator Economy infrastructure layer**,
starting with housing.

We are NOT: - A listing portal - A brokerage - A mortgage broker - A
media production company

We ARE: - A structured campaign marketplace - An attention routing
layer - A creator monetization engine - A housing-intent data
infrastructure

Property is Phase 1. The long-term vision is vertical creator liquidity.

------------------------------------------------------------------------

# 2. Strategic Wedge

## Primary Wedge (Phase 1)

Agent-Creators (B)

Why: - They control listings - They already create content - They
already spend on marketing - They need differentiation

Secondary Wedges (Later): A) Independent housing creators\
C) Developers\
D) Renovation influencers\
E) Everyday micro-promoters

------------------------------------------------------------------------

# 3. Platform Architecture (MVP)

## Attention Flow

KOL Native Post (TikTok / IG / YouTube) → Smart Campaign Link → Nadara
Mobile Landing Page → Soft Engagement → Save-to-Account Gate →
Personalized Feed

## Core MVP Behavior

Primary Metric: **Save-to-Account Ratio**

Why: - Signals intent - Creates owned users - Enables segmentation -
Builds gravity without transaction dependency

------------------------------------------------------------------------

# 4. Content Architecture

We operate 3 content pillars:

## A. Discovery

-   Listing micro-reviews (30s)
-   New development features
-   Short-term rental properties

## B. Improvement

-   Renovation tips
-   Maintenance hacks
-   Design inspiration
-   House lifestyle

## C. Decision

-   Rent vs Buy comparisons
-   Investment breakdowns
-   Neighborhood intelligence
-   Mortgage education shorts

All content must route back to Listings or Intent Capture.

------------------------------------------------------------------------

# 5. Dynamic Comparison Tool (Key Hook)

When a user signs up after Rent vs Buy content:

They see: - Monthly payment comparison - Estimated buying power - 3
matching listings - Toggle slider (rent vs own) - Optional pre-qual CTA

This validates intent immediately.

------------------------------------------------------------------------

# 6. Revenue Model (MVP)

## Layer 1 -- Agent-Funded Campaigns

\$750--\$1,200 per listing campaign

## Layer 2 -- Creator Base + Performance

\$300--\$500 base + performance bonuses + sponsor split (when
applicable)

## Layer 3 -- Sponsor Bundles

Mortgage / Insurance / STR Financing Buy segmented intent packages

## Layer 4 -- Platform Take Rate

Structured % on campaign liquidity (Not transaction commission
dependent)

------------------------------------------------------------------------

# 7. Sponsor Strategy (Ratehub Path)

Target: Performance-driven mortgage aggregators

Positioning: "Upstream mortgage intent capture inside creator-driven
housing discovery."

Requirements before approach: - Intent tagging live - Save-to-account
metrics - Rent vs Buy usage data - Outbound tracking - Geo segmentation

Pilot model: CPA or Rev-share

------------------------------------------------------------------------

# 8. Bot & Fraud Prevention

-   SMS verification
-   Device fingerprinting
-   IP clustering detection
-   Reward on verified actions only
-   No raw click rewards

------------------------------------------------------------------------

# 9. Governance Principles (3D + 5D Alignment)

To avoid becoming extractive:

-   Transparent revenue splits
-   Clear performance dashboards
-   No opaque algorithm throttling
-   No pay-to-suppress exposure
-   Creator empowerment model
-   Fair take-rate ceiling

We are the routing layer, not the gatekeeper.

------------------------------------------------------------------------

# 10. Long-Term Architecture

Phase 1: Creator Campaign Liquidity\
Phase 2: Intent Segmentation & Sponsor Routing\
Phase 3: AI-Driven Content-to-Intent Matching\
Phase 4: Scheduling Engine Integration\
Phase 5: Transaction Enablement (Optional Layer)

Ultimate Goal: Creator-powered vertical commerce infrastructure.

------------------------------------------------------------------------

# 11. Daily Return Hook

Primary Habit Loop: Rent vs Buy → Personalized listing feed → Save →
Alerts → Similar property notifications → Return visits

Secondary Loop: Reno content → Related listings → Investment videos →
Watchlist updates

------------------------------------------------------------------------

# 12. Strategic Guardrails

Do NOT: - Become a generic video platform - Overexpand content without
routing logic - Depend on transaction commission early - Overbuild AI
before behavioral density - Chase enterprise sponsors too early

Focus on: - Density within a niche - Behavioral tagging - Measurable
intent clusters - Campaign repeatability

------------------------------------------------------------------------

# Closing Thesis

Nadara is building:

Attention → Account → Intent → Liquidity → Sponsorship → Ecosystem

We are not fighting incumbents. We are redesigning coordination.
