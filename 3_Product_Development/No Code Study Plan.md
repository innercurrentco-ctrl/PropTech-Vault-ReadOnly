### 📚 Learning Plan & Goals

Here’s a structured path you can follow, broken into weeks with exercises. I can walk with you through each step.

#### **Week 1 – Familiarization**

- Goal: Understand the basics of Webflow and Bubble.
    
- Exercises:  
    • Watch the Webflow 15‑minute crash video.  
    • Watch the Bubble crash course.  
    • Pick one simple page (e.g., landing page) and replicate it in Webflow.
    

#### **Week 2 – Data & Logic Setup**

- Goal: Build the underlying structure (database, user roles, onboarding).
    
- Exercises:  
    • Map out your user types (Regular User, Verified Owner/Seller, Agent, Verified Agent).  
    • In Bubble: create “User” data type with fields (type, legal name, mobile, email).  
    • In Webflow/Airtable: set up a simple database for listings or users.
    

#### **Week 3 – Build Core Feature**

- Goal: Build one working flow (e.g., user registration + listing submission).
    
- Exercises:  
    • In Bubble: build registration page and save data.  
    • Connect listing submission: user uploads listing, data saved, listing appears in database.  
    • Add basic logic: role‑based access (owner vs agent) to submission page.
    

#### **Week 4 – Test & Iterate**

- Goal: Have a mini usable MVP you can show someone.
    
- Exercises:  
    • Get 2‑3 peers/friends to test your MVP flow.  
    • Collect feedback: what’s confusing, what’s slow.  
    • Iterate: refine UI, fix logic bugs, improve UX.
    
- Deliverable: A clickable prototype you can demo.
    

#### **Ongoing (Months 2–3)**

- Add more features (affiliate links, video uploads, tracking).
    
- Integrate automation (Zapier/Make) for workflows (e.g., new listing → email to owner → listing posted).
    
- Begin collecting early users, feedback, metrics (time to upload, number of submissions).
    
- Prep for next funding/grant pitch: “Here’s what we built in 30 days”.
