### **What You Can Build With No-Code/Low-Code**

You can build a surprising amount without writing much code:

- **Web apps** (user portals, marketplaces, booking platforms)
    
- **Internal tools** (dashboards, admin panels)
    
- **CRMs/lead management**
    
- **Directory or listing sites**
    
- **Landing pages & email capture**
    
- **Automation workflows** (e.g., notifications, document generation)
    
- **Data-driven apps** (forms → database → analytics)
    

### 🔧 Tools to Start With (Stack Example)

|Function|Tool|Why It's Useful|
|---|---|---|
|Frontend UI|**Webflow** or **Bubble**|Bubble: full web app logic / Webflow: great visuals|
|Database backend|**Airtable**|Easy spreadsheet-style data + API access|
|Logic + automation|**Zapier** or **Make**|Automate workflows: emails, forms, updates|
|Forms|**Tally** or **Typeform**|Simple UX for collecting structured input|
|Analytics/Tracking|**Google Analytics**, Outseta, PostHog|Monitor user behavior, funnel drop-off|

### 📘 30-Day Strategic Learning Plan: From Zero to MVP

#### **Week 1: Orientation & Idea Shaping**

**Goals:**

- Understand no-code tool categories
    
- Define your MVP scope (must-have features only)
    

**Exercises:**

- Watch Webflow/Bubble 101 videos
    
- Write out 3 user journeys
    
- Draft a wireframe (use Whimsical or Figma)
    

---

#### **Week 2: Build a Basic UI + Data Model**

**Goals:**

- Build a simple 1-page app (landing + form)
    
- Set up Airtable with schema matching your idea
    

**Exercises:**

- Create Airtable tables for your users, leads, and data
    
- Use Bubble to build the interface
    
- Link inputs to data in Airtable
    

---

#### **Week 3: Add Automation & Interactivity**

**Goals:**

- Trigger actions (emails, confirmations)
    
- Add logic (filters, calculations, data display)
    

**Exercises:**

- Use Zapier/Make to send email confirmations
    
- Create filtered views (e.g., by user or status)
    
- Make a dashboard from Airtable data
    

---

#### **Week 4: MVP Polish + Testing**

**Goals:**

- Make your app usable for a small group
    
- Run a mini test with friends or 2-3 users
    

**Exercises:**

- Create test use cases and run walkthroughs
    
- Refine onboarding (explainers, flows)
    
- Ask for feedback and iterate
