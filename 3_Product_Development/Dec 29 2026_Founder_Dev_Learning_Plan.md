**🧭 Visionary Founder Developer Learning Plan (JavaScript / React / Next.js / Node.js / TypeScript)**

---

### ✅ Tools Setup
- **IDE**: [Visual Studio Code](https://code.visualstudio.com/) (✅ Already Installed)

---

### 📚 Phase 1: JavaScript Fundamentals
**Goal**: Build a solid base in JavaScript so React, Next.js, and Node.js feel natural.

- [JavaScript Full Course for Beginners – freeCodeCamp (YouTube)](https://www.youtube.com/watch?v=jS4aFq5-91M)
  - Duration: ~4 hours
  - Tip: Do 1 hour/day over 4–5 days

---

### 📚 Phase 2: TypeScript Basics
**Goal**: Learn modern, safer JavaScript with TypeScript

- [TypeScript Crash Course – Traversy Media (YouTube)](https://www.youtube.com/watch?v=BCg4U1FzODs)
  - Duration: ~50 minutes

---

### 📚 Phase 3: React (Frontend Foundation)
**Goal**: Build dynamic user interfaces (web or app)

- [React in 100 Seconds – Fireship (YouTube)](https://www.youtube.com/watch?v=Tn6-PIqc4UM)
  - Great intro (~2 minutes)
- [React Beginner Crash Course – Net Ninja (YouTube)](https://www.youtube.com/watch?v=w7ejDZ8SWv8)
  - Duration: ~2 hours

---

### 📚 Phase 4: Next.js (Web App Framework)
**Goal**: Learn React + server capabilities for production apps

- [Next.js Full Course – freeCodeCamp (YouTube)](https://www.youtube.com/watch?v=F5mRW0jo-U4)
  - Duration: ~8 hours

---

### 📚 Phase 5: Node.js (Backend Basics)
**Goal**: Power your app with server logic

- [Node.js Crash Course – Traversy Media (YouTube)](https://www.youtube.com/watch?v=fBNz5xF-Kx4)
  - Duration: ~1 hour

---

### 📝 Daily Plan Suggestion
| Day | Focus |
|-----|-------|
| 1-4 | JavaScript Full Course |
| 5   | TypeScript Crash Course |
| 6   | React 100s + React Crash Course |
| 7-8 | Next.js Full Course |
| 9   | Node.js Crash Course |
