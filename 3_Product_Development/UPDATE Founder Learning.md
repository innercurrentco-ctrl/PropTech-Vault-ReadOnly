# InnerCurrent Founder Fluency Vault

## Purpose
Build enough technical fluency to:
- Direct developers with confidence
- Prototype with no-code/low-code tools
- Integrate AI (LLMs) and APIs into products
- Design systems that scale without getting lost in code

---

## Weekly Breakdown

### Week 1: Systems Thinking + Interface Prototyping
- **Goal:** Understand tech stacks, platforms, and visual builders
- **Learn:**
  - [Webflow 101](https://webflow.com/university)
  - [FlutterFlow Overview](https://docs.flutterflow.io/getting-started/overview)
  - [What is Firebase](https://firebase.google.com/docs/)
- **Task:**
  - Build a 1-page portfolio or mock dashboard UI
  - Explore Firebase Auth dashboard
  - Write 3 insights about Web vs App platforms

---

### Week 2: JSON, APIs & Automation Fluency
- **Goal:** Know how to read/write basic API flows
- **Learn:**
  - [Postman API Intro](https://learning.postman.com/docs/getting-started/introduction/)
  - [JSON Crash Course](https://www.youtube.com/watch?v=iiADhChRriM)
  - [Make.com intro](https://www.youtube.com/watch?v=HgGzv5JSQxA)
- **Task:**
  - Connect dummy API (like JSONPlaceholder) to Airtable
  - Read data using Postman + display in Make.com or Glide
  - Generate API prompt using GPT: “Summarize this JSON schema”

---

### Week 3: AI Integration Basics
- **Goal:** Use GPT / LLMs inside apps via API
- **Learn:**
  - [OpenAI API Quickstart](https://platform.openai.com/docs/quickstart)
  - [Zapier + OpenAI Tutorial](https://www.youtube.com/watch?v=OAIy_b0VwzY)
  - [n8n GPT Node](https://n8n.io/integrations/openai/)
- **Task:**
  - Create a Zap/n8n flow: Form ➝ GPT ➝ Email Response
  - Build prompt for real estate appraisal assistant
  - Write a use-case outline for GPT in your MVP

---

### Week 4: Secure Workflows (Auth + Data Submission)
- **Goal:** Basic flows for user auth + listing creation
- **Learn:**
  - [Firebase Auth for Web](https://firebase.google.com/docs/auth)
  - [Bubble Auth + Forms](https://manual.bubble.io/core-resources/handling-users)
  - [FlutterFlow Firebase Auth](https://docs.flutterflow.io/integrations/firebase-authentication)
- **Task:**
  - Build sign-up/login form in your platform of choice
  - Submit a dummy real estate listing to database
  - Sketch a user journey with auth + listing flow

---

### Week 5: Developer Handoff + MVP Spec Writing
- **Goal:** Write specs developers can act on
- **Learn:**
  - [How to Write a Feature Spec (Video)](https://www.youtube.com/watch?v=En4R1zX5T1I)
  - [API Docs + Swagger Basics](https://swagger.io/docs/specification/about/)
  - [Draw.io](https://app.diagrams.net/) for system diagrams
- **Task:**
  - Draft 1-page MVP spec for your platform
  - Draw system diagram of data flow (users, listings, GPT call)
  - Upload to Obsidian for linking to other research

---

### Week 6: GTM & Growth Tactics (No-Code-First Launch)
- **Goal:** MVP polish + plan launch using tools
- **Learn:**
  - [Carrd for Landing Pages](https://carrd.co/)
  - [Webflow + Forms](https://university.webflow.com/lesson/forms)
  - [LLM Email Reply Bot](https://www.youtube.com/watch?v=0TrcB7tS4tw)
- **Task:**
  - Build MVP front-end (Webflow or Bubble)
  - Setup email capture + auto responder with GPT
  - Draft early adopter onboarding sequence

---

- App Builders: FlutterFlow, Bubble, Webflow
- Backend: Firebase, Supabase, Airtable
- Automations: n8n, Zapier, Make.com
- Storage: Google Drive, Notion, Obsidian Vault
