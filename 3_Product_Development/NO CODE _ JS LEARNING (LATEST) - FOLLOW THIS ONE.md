**6-Week Learning Plan: No-Code (Webflow, Bubble) + JS, API, JSON Fluency**

---

**WEEKLY STRUCTURE:**
- **5 Days a Week** (Mon–Fri)
- **4 Hours Daily Split:**
  - **2 hrs Morning:** No-Code Tools (Webflow / Bubble)
  - **2 hrs Afternoon:** JS + API + JSON

---

### WEEK 1: Foundations
**No-Code Focus:**
- Webflow 101 (webflow.com/university)
  - Layouts, containers, flex/grid
  - Styling basics, nav bars
- Create a single-page portfolio site

**Code Focus:**
- JS Basics (Variables, Loops, Functions)
- JSON structure & use cases
- Intro to APIs (GET requests demo)

**Courses:**
- [freeCodeCamp JS Basics](https://www.freecodecamp.org/learn)
- [Webflow 101 Crash Course](https://webflow.com/university)

**Exercise:**
- Build Webflow site replicating a simple template
- Write a JS script to parse JSON and log values

---

### WEEK 2: CRUD Operations + Bubble Setup
**No-Code Focus:**
- Bubble.io Introduction
- Build user signup/login workflows
- Bubble database basics

**Code Focus:**
- Objects, Arrays in JS
- Fetch API
- Simple CRUD using JSONPlaceholder API

**Courses:**
- [Bubble Crash Course](https://www.youtube.com/watch?v=ke0cVYU1a8g)
- [MDN Fetch API Docs](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API)

**Exercise:**
- Bubble app: To-do app with login and database
- JS app: Fetch and display dummy user data from API

---

### WEEK 3: Intermediate Design + API Integrations
**No-Code Focus:**
- Webflow CMS
- Embedding JS widgets into Webflow

**Code Focus:**
- Asynchronous JS (Promises, Async/Await)
- Real-world API integration (e.g. OpenWeather, Notion, Airtable)

**Exercise:**
- Build a blog in Webflow using CMS
- JS: Build weather dashboard w/ fetch + async await

---

### WEEK 4: Zapier, Airtable + JSON Parsing
**No-Code Focus:**
- Zapier Automation
- Airtable as a backend
- Connect Webflow / Bubble to Airtable

**Code Focus:**
- Parse deeply nested JSON
- Custom API calls and headers

**Courses:**
- [Zapier 101](https://zapier.com/learn)
- [Airtable Getting Started](https://support.airtable.com/)

**Exercise:**
- Create a Bubble CRM using Airtable
- Write a JS parser to extract values from nested JSON

---

### WEEK 5: Deployment, Hosting, Authentication
**No-Code Focus:**
- Webflow forms, submissions, and automation
- Bubble advanced workflows

**Code Focus:**
- JWT tokens, Auth headers
- POST/PUT API operations

**Exercise:**
- Deploy Bubble app w/ auth and form
- JS: Post form data to webhook endpoint

---

### WEEK 6: Final MVP & Polish
**Build:**
- One MVP in Bubble (e.g. Property Matching App or Booking Tool)
- Landing page in Webflow
- Use Airtable backend + Zapier

**Submission:**
- JSON structure + documentation
- JS logic demo (fetch / push data to Airtable)
- Share Webflow/Bubble links
