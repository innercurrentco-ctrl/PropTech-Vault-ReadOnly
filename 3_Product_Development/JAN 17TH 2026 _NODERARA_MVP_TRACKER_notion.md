## 📲 iOS / Android Practice Builds (Low-Code + JS-Based)
### 📱 Mini Projects to Practice
| Name | Type | Tech Stack | Purpose |
|------|------|------------|---------|
| Influencer Reward App (Mock) | Mobile | Flutter or Expo (React Native) | Simulate sharing + points |
| Creator Form App | Mobile | React Native + Firebase | Capture user input + auto track |
| Points Display UI | Mobile/Web | Flutter or HTML+JS | Show user dashboard & reward balance |

### 🛠 How to Practice
1. Use **FlutterFlow** or **Expo Snack** for quick front-end prototypes
2. Simulate logic with JS only first (fake data → calculate points)
3. Use **Firebase** (free tier) to store data from your prototype apps
4. Follow tutorials like:
   - "Flutter Beginner CRUD with Firebase"
   - "React Native + Firebase Auth & Database"
5. Gradually shift from **JS logic** to **mobile UI build**
